# ⚔️ Battle Arena 2D

### A 2D Battle Game Developed Using JavaFX

## 📌 Project Overview

Battle Arena 2D is a graphical 2D battle game developed using Java and JavaFX. Players can select different characters and fight against enemies in an interactive battle environment.

## 🎮 Game Features

- Character Selection (Warrior, Mage, Archer)
- 2D Graphical Battle Environment
- Player Health System
- Enemy Health System
- Attack and Enemy Attack Mechanics
- Weapon Upgrade System
- Damage and Scoring System
- Level Progression

## 🛠️ Technologies Used

- Java
- JavaFX
- Maven
- IntelliJ IDEA

## 🧠 OOP Concepts

- Inheritance
- Encapsulation
- Polymorphism
- Abstraction (if implemented)

## 🚀 How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure Java and JavaFX dependencies.
4. Reload the Maven project.
5. Run the `BattleArenaFX` main class.
